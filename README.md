# ResourceHub – Full-Stack Resource Management System

ResourceHub is a full-stack web application developed using **React.js, Node.js, Express.js, and PostgreSQL**. It is designed to simplify the management and reservation of shared organizational resources, including facilities and equipment.

The application provides two types of user access:

**1. Normal User**
- View the available resources in the catalog.
- Filter resources based on their availability.
- Reserve available resources by selecting a date and time.
- View their scheduled reservations.

**2. Admin User**

The system includes an administrator account with the following login credentials:
- **Email:** admin@resourcehub.com
- **Password:** 12345

The administrator can:
- View available resources.
- Add new facilities and equipment to the resource catalog.

Overall, ResourceHub provides a centralized platform for managing organizational resources, making the reservation process more convenient and improving resource utilization.
